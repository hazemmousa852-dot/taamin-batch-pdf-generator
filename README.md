# معبّي الدفعات — Excel إلى نماذج التأمينات PDF

**معبّي الدفعات** مشروع مستقل لتحويل ملف Excel منظم إلى نماذج التأمينات **س1 وس6**. يحتوي ملف Excel على شيت ثابت لبيانات المنشأة والمفوّض وشيت متعدد الصفوف للمؤمن عليهم، ثم ينتج التطبيق ملف PDF مجمعًا بالترتيب أو ZIP يضم الملفات المنفصلة.

> المعالجة الحالية تعمل داخل المتصفح. ملفات Excel والبيانات المدخلة لا تُرسل إلى خادم من داخل التطبيق.

## ما الذي توفره النسخة الحالية؟

تبدأ الأداة بسجل فارغ لإدخال البيانات الأساسية، ثم تعرض السجلات في جدول مع حالة الاكتمال. يمكن إضافة سجلات متعددة، والبحث بالاسم أو الرقم، والتبديل بين أقسام بيانات المؤمن عليه والعمل والأجر والعنوان. كما تعرض الواجهة معاينة تقريبية مرتبطة بالسجل المحدد.

عند اكتمال السجلات، يستطيع المستخدم تنزيل PDF مستقل للسجل المحدد، أو PDF مجمع لجميع النماذج وراء بعضها، أو ZIP يحتوي ملفًا منفصلًا لكل مؤمن عليه. يتم استخدام قالب النموذج الأصلي المرفق، مع تعبئة حقول AcroForm وخط عربي مضمّن لتحسين ظهور النص العربي.

## تشغيل المشروع محليًا

```bash
pnpm install
pnpm dev
```

ولفحص النسخة الإنتاجية:

```bash
pnpm check
pnpm test
pnpm build
```

## أعمدة Excel

قالب Excel الذي ينزله التطبيق يحتوي شيتين: `بيانات المنشأة والمفوض` للبيانات المشتركة، و`بيانات المؤمن عليهم` بحيث يمثل كل صف نموذجًا مستقلًا. الأداة تطابق الأسماء العربية الشائعة تلقائيًا.

| المجموعة | الأعمدة المدعومة |
| --- | --- |
| الهوية | اسم المؤمن عليه، الرقم القومي، الرقم التأميني، تاريخ الميلاد، النوع، الفئة |
| العمل والاشتراك | اسم المنشأة، رقم المنشأة، المكتب، المؤهل، المهنة، كود المهنة، تاريخ بدء الاشتراك، كود الاشتراك، نوع المدة |
| الأجر والعجز | الأجر الأساسي، الأجر المتغير، الأجر الشامل، تاريخ بداية العجز / الزيادة، نسبة العجز / الزيادة |
| العنوان والتواصل | الدولة، المدينة، المحافظة، الشياخة / القرية، الشارع، القسم / المركز، التليفون، البريد الإلكتروني، جهة العمل، المدير المسؤول، تحريرًا في |

تُقرأ ملفات `.xlsx` و`.xls`. الصفوف الفارغة تُتجاهل، وتُدمج البيانات المشتركة تلقائيًا مع كل صف من المؤمن عليهم.

## بنية مهمة

توجد خريطة ربط الحقول داخل `client/src/lib/pdf.ts` لأن قالب PDF الأصلي يستخدم أسماء عامة مثل `Text11` و`Text82` بدل أسماء عربية. تفاصيل الفحص محفوظة في `form-analysis.md`، واختبارات المتصفح محفوظة في `browser-tests.md`.

تتحقق الأداة قبل التصدير من الحقول المطلوبة لكل قالب، وطول الرقم القومي، وصيغ التواريخ والأجور. كما تحتفظ الأرقام التأمينية وأرقام المنشآت بالأصفار الموجودة في بدايتها. لا تعرض الواجهة إلا الحقول التي لها موضع مُراجع داخل القالب المحدد. يمكن التحقق من بقاء خرائط القوالب سليمة بعد استبدال أي PDF بالأمر:

```bash
python scripts/verify_pdf_fields.py
```

## ملاحظات قبل الاعتماد التشغيلي

ينبغي تجربة سجل حقيقي واحد مع قارئ PDF والطابعة المستخدمين في المكتب قبل الاعتماد الكامل على دفعات كبيرة. نموذج س6 يضيف حقول مقدم الطلب، صفته، هاتفه، رقمه القومي، العنوان، تاريخ انتهاء الاشتراك، وسبب الانتهاء. الحقول الأصلية في النموذج عامة، لذلك تم إعداد خريطة مستقلة لكل قالب مبنية على أسماء ومواضع حقوله، وقد تحتاج إلى تعديل محدود إذا تغيّر إصدار النموذج الرسمي.

## الحقوق والأصول

القالب المرفق والأصول البصرية المستخدمة في المشروع مرتبطة بهذه النسخة من الموقع. لا تضع ملفات الصور أو PDF الكبيرة داخل `client/public`؛ الأصول الدائمة للمشروع محفوظة في تخزين الموقع ويُشار إليها من خلال مسارات `manus-storage`.
